**Goal:** Build and deploy `mhajiyev-portfolio-website`, a static MkDocs + Material portfolio site showcasing the `data-portfolio` projects, an about/background section, a blog, and static contact links.

```markdown
# Analytics Pipeline (DuckDB)

A small ELT pipeline that pulls macroeconomic indicators from
[FRED](https://fred.stlouisfed.org/) (Federal Reserve Economic Data) into
a local DuckDB warehouse, then does exploratory analysis on top of it.

## What it does

- **Extract:** downloads raw CSVs directly from FRED's public graph
  endpoint for a list of series (e.g. `DGS10` — 10-Year Treasury yield,
  `DCOILWTICO` — WTI crude oil price). No API key required.
- **Transform:** cleans and forward-fills the series in pandas, filtered
  to data from 2023-01-01 onward.
- **Load:** performs an idempotent `INSERT OR REPLACE` upsert into a
  `fact_macro_metrics` table in DuckDB, keyed on `metric_date`.
- **Explore:** a Jupyter notebook does exploratory analysis and
  visualization on top of the resulting DuckDB file, including a rolling
  30-day correlation between series.

## Tech stack

Python, DuckDB, pandas, `pandas-datareader`, matplotlib, `uv`.

## Links

- [Source code](https://github.com/MahammadHajiyev2024/data-portfolio/tree/main/01-analytics-pipeline-duckdb)
- [Exploration notebook](https://github.com/MahammadHajiyev2024/data-portfolio/blob/main/01-analytics-pipeline-duckdb/notebooks/01_eda_and_exploration.ipynb)
```
